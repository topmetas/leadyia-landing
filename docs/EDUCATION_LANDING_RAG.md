# Landing LeadyIA Educação — RAG / Portfólio

## Rotas
- `/educacao`
- `/education`
- `/escola`

## Subdomínios sugeridos
- `educacao.leadyia.com`
- `education.leadyia.com`
- `escola.leadyia.com`

## Widget
```html
<script
  src="https://widget.leadyia.com/loader.js"
  data-tenant-id="TENANT_ID_EDUCATION"
  data-segment="education"
  async
></script>
```

## Objetivo
Criar uma landing realista para demonstração de IA em negócios educacionais: escolas, cursos, mentorias, reforço escolar, psicopedagogia e produtos educacionais.

## RAG
O arquivo `public/rag/education-rag.json` contém regras, intenções, CTAs e FAQ para indexação no dashboard.

## Regras de segurança
- Não diagnosticar dificuldades de aprendizagem.
- Não prometer resultados pedagógicos absolutos.
- Encaminhar casos sensíveis para equipe humana.
- Gerar Pix apenas quando houver regra configurada.
