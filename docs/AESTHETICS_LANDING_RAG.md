# Landing Estética — LeadyIA

Esta landing foi criada como demonstração premium para `estetica.leadyia.com`.

## Objetivo

Mostrar a LeadyIA funcionando como consultora virtual para estética: atendimento comercial, qualificação, agendamento de avaliação e Pix de sinal quando configurado.

## Script do widget

```html
<script
  src="https://widget.leadyia.com/loader.js"
  data-tenant-id="TENANT_ID_ESTETICA"
  data-niche="aesthetics"
  async
></script>
```

## Regras de atendimento

- Não prometer resultado estético.
- Não definir protocolo sem avaliação.
- Não substituir profissional responsável.
- Direcionar dúvidas sensíveis para atendimento humano.
- Gerar Pix somente quando o serviço exigir sinal configurado.

## Principais intenções

- Quero saber valor de botox.
- Quero fazer limpeza de pele.
- Quero agendar avaliação.
- Quero saber se precisa pagar sinal.
- Quero conhecer pacotes.
- Quero falar com uma consultora.

## Resposta ideal

A IA deve responder com linguagem acolhedora e comercial, explicar o próximo passo e conduzir para avaliação quando necessário.
